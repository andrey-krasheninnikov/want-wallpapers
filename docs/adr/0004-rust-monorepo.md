# 0004: Rust API, монорепозиторий и VPS

Статус: принято. Заменяет сведения о backend, хранении и деплое в ADR 0001–0003.

Frontend остаётся Astro/React/Tailwind/shadcn с прежними публичными маршрутами и четырьмя языками в `frontend/`. `backend/` содержит Axum/Tokio/SQLx, PostgreSQL 18 и миграции. Один непривилегированный контейнер раздаёт статическую сборку и API за существующим Traefik. PostgreSQL внешний; соединение в production обязательно проверяет сертификат и hostname (`verify-full`). Контейнер не получает Docker socket.

Каталог начинается с текущего snapshot: три коллекции и 25 дизайнов. Социальные данные Firebase не импортируются. Миграция snapshot выполняется один раз через историю SQLx. В production приложение не запускает DDL; отдельная операция миграции использует роль владельца. Версия релиза хранится в корневом package.json и Cargo workspace.

Публичные страницы и поиск остаются статическими. Изменения каталога требуют API export, нового snapshot и сборки. Админка сообщает об этом; оценки, комментарии, жалобы и обращения изменяются сразу. Архив не освобождает ID/slug/номер и сохраняет социальные данные.

У администратора пароль Argon2id и TOTP. Сессия хранится в PostgreSQL, имеет 8 часов абсолютного срока и 30 минут простоя. TOTP нельзя повторно использовать. Изменение логина, hash или TOTP отзывает старые сессии. Анонимные посетители используют отдельный HttpOnly cookie сроком до года. Изменения из браузера требуют точного Origin и CSRF. PostgreSQL хранит лимиты, поэтому перезапуск не сбрасывает защиту. Для IP учитывается только цепочка от явно доверенного proxy.

Автоматизация получает отдельный Bearer secret, ограниченный каталогом. Импорт manifest атомарен и допускает точный повтор без записи; частичный или изменившийся каталог даёт conflict. Версии защищают формы от конкурентного перезаписывания. Локальные тесты используют только отдельный PostgreSQL 18, а UI-прогоны создают новые БД с уникальными именами.

Региональная проверка остаётся в браузере и управляет доступностью функций, а не авторизацией API. Прямой API защищён отдельно. Админка не использует региональную проверку. Firebase сохраняется только для Analytics после согласия и разрешённого региона. Отсутствие measurement ID отключает Analytics. Закрытые обращения удаляются ежедневной задачей спустя год; повторное открытие отменяет удаление.
