# Видеообложки коллекций

Сначала загрузите MP4 и PNG-постер в папку коллекции на `https://want-foundation.s3.twcstorage.ru/`. Браузерной загрузки файлов нет. В админке заполните оба URL либо добавьте поле в manifest:

```json
"videoCover": {
  "src": "https://want-foundation.s3.twcstorage.ru/wallpapers/assets/collections/0004-where-stars-graze/cover.mp4",
  "poster": "https://want-foundation.s3.twcstorage.ru/wallpapers/assets/collections/0004-where-stars-graze/cover.png"
}
```

Это пример адресов, не подтверждение наличия файлов. Имя файла содержит только латинские буквы, цифры, дефисы и подчёркивания. Оба файла находятся непосредственно в папке этой коллекции. Параметры URL, redirects и другие хосты запрещены.

Видео: MP4/H.264, одна видеодорожка без аудио, положительная длительность до 10 секунд, размер до 8 MiB. Для браузеров используйте 8-bit yuv420p и faststart. Постер: PNG до 8 MiB, обе стороны не меньше 500 px. Загрузку ограничивают размер и таймаут. Сборка проверяет metadata и полное декодирование видео, декодирует постер и создаёт локальный WebP с размерами. Невалидный или недоступный файл блокирует сборку. FFmpeg получает только локальный временный файл и не имеет сетевых протоколов.

Админка проверяет URL и сохраняет изменения с optimistic version. Файлы проверяются при сборке, поэтому успешное сохранение ещё не подтверждает пригодность видео. Выполните `make catalog-pull`, build и согласованный release для обновления публичных страниц. Переводы, адреса страниц и скачиваемые desktop/mobile PNG сохраняются. Для удаления видео очистите оба поля; следующий export/build вернёт обычную обложку из первого дизайна.

Постер отображается сразу и используется в Open Graph. Видео с CDN загружается только после появления обложки в viewport, воспроизводится без звука, inline и в loop. Уход из viewport и скрытие вкладки останавливают видео. Кнопка паузы доступна клавиатурой; ручная пауза сохраняется при прокрутке. Reduced motion, поддерживаемые настройки экономии трафика, отключённый JavaScript, неподдерживаемый формат, ошибка загрузки или запрет autoplay сохраняют постер. При запрете autoplay можно использовать кнопку воспроизведения. Экономия трафика учитывается через доступные браузеру saveData/prefers-reduced-data; отсутствие этих возможностей не позволяет определить системную настройку.

Для native build/test нужны работающие `ffmpeg` и `ffprobe` в PATH. В Linux: `sudo apt-get install --no-install-recommends ffmpeg`. Dockerfile устанавливает инструменты только в builder; runtime и VPS их не получают. `make test-cover-media` проверяет реальные MP4 fixtures и отказы; этот набор входит в `make test`. Browser fixtures подменяют только CDN и HTML-ответ, используя настоящие компоненты, CSS и клиентский контроллер. Эти проверки не подтверждают production CDN или конкретное пользовательское видео.

Включайте videoCover в production после выпуска поддерживающей версии API и инструментов каталога. Старый Rust backend отклоняет неизвестное поле; перед возвратом к версии без поддержки видео сначала уберите videoCover через новый API и проверьте export. Отсутствие SQL-миграции не гарантирует совместимость старого runtime с новыми JSONB-записями. Не меняйте production каталог и не выполняйте rollback автоматически ради этой процедуры.
