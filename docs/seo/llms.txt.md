# Публичный llms.txt

`https://wallpapers.want.foundation/llms.txt` формируется при Astro build из публичного snapshot каталога и действующей лицензии. Документ использует [формат llms.txt](https://llmstxt.org/): название, краткое описание, условия использования перед разделами и списки ссылок под H2. Подписи разрешений, запретов и владения сохраняют смысл текста страницы лицензии.

Разделы `en`, `ru`, `zh-cn`, `pt-br` содержат главные страницы, каталог коллекций, каждую публичную коллекцию и обои, лицензию и условия использования. Английская версия находится в корне домена. Общий публичный layout содержит `rel="describedby"` на документ. Rust раздаёт успешные GET/HEAD как `text/plain; charset=utf-8`; отсутствующий файл возвращает обычный HTML 404.

После изменения каталога выполните `make catalog-pull`, проверьте изменения snapshot, затем build и согласованный release. Изменения становятся публичными после deployment нового образа. Проверка сборки сверяет ссылки с canonical HTML-графом, требует четыре локали и полный текущий каталог, отклоняет приватные, посторонние, повторные и отсутствующие ссылки. Текст названий и описаний экранируется для Markdown; переносы внутри ссылок сворачиваются в пробелы. Социальные данные и приватные настройки в документ не включаются.

Для production-приёмки сохраните дату, deployed source/image, HTTP status и Content-Type, checksum документа и результаты проверки публичных ссылок. Свежий платный аудит Semrush отложен по решению владельца для #18. HTTP-проверки не подтверждают результат этого аудита или изменение поискового ранжирования.

Production-приёмка v1.6.0 и отложенный Semrush зафиксированы в [архиве от 13 октября 2026](2026-10-13-llms-audit.md).
