# История изменений

## Не выпущено

## [1.6.0] - 2026-10-13

### Добавлено

- Коллекции поддерживают MP4/H.264 видеообложки с PNG-постером. Видео загружается при появлении в viewport; пауза, reduced motion и ошибки воспроизведения сохраняют доступный постер. API и инструменты каталога проверяют адреса и media перед публикацией.

### Исправлено

- llms.txt сохраняет разрешения, запреты и владение из действующей лицензии, ссылки на Terms и четыре локали. Публичные страницы содержат discovery metadata; успешная выдача использует UTF-8 text/plain. Сборка проверяет структуру и актуальные публичные ссылки.
- Проверка HTML-графа отклоняет публичную навигацию на страницы ошибок и проверяет отсутствие hreflang у исключённых страниц.
- Backup worker допускает точное изолированное public-media правило Prizmaxis, сохраняя исключение backups и отказ неизвестным S3 grants. Bucket policy не изменяется.

### Ограничения

- Свежий платный аудит Semrush отложен владельцем. HTTP-проверки и CI не подтверждают результаты Semrush или улучшение поискового ранжирования.
- Локальный FFmpeg на Mac не запускается из-за отсутствующего x265 dylib. Media tests и полный UI проверяются Linux CI; конкретные production видео требуют отдельных опубликованных файлов и каталожного release.

## [1.5.1] - 2026-10-13

### Исправлено

- Origin robots.txt сохраняет 47 действующих запретов краулеров стандартными директивами, sitemap и приватные исключения admin/API. Проверка сборки учитывает crawler groups и отклоняет некорректную политику.
- Допуск релиза принимает UTC timestamps с суффиксом `Z` на Python 3.9.

### Production-проверка

- После деплоя владелец отключает managed-добавку robots для зоны want.foundation, сохраняя остальные настройки Cloudflare. Затем проверяются effective robots и доступ публичных страниц, sitemap и ресурсов.
- Свежий аудит Semrush предоставляется отдельно. Локальные HTTP-пробы и успешный CI не подтверждают доступ настоящего краулера; #17 остаётся открытым до production-приёмки.

## [1.5.0] — 2026-10-12

### Добавлено

- Защищённый release tag запускает deployment точного проверенного образа через отдельный SSH account с ограниченными командами. Работающий сайт сохраняется до проверки образа, подключений и backup.
- Перед миграцией backup шифруется, сохраняется приватно на 30 дней и восстанавливается на Mac в изолированной PostgreSQL 18. При ошибке или недоступном worker миграция блокируется.
- Deployment сохраняет состояние и прежний образ/config. Автоматический rollback разрешён при подтверждённой совместимости schema/history; остальные ошибки требуют оператора.
- Ручной повтор использует исходный immutable digest и его успешный main run/attempt, даже после новой публикации того же commit.

### Исправлено

- Миграции используют только migrator URL/CA, egress и 128 MiB памяти даже при наследовании старого operational Compose.
- Добавлены проверяемые SQL-процедуры изоляции PostgreSQL от известных ролей других приложений и восстановления ограниченных runtime grants.

### Подготовка и проверка

- Установщик допускает ограниченные CI/backup SSH-учётки при существующем глобальном AllowUsers, сохраняя доступ администратора и запрет остальных пользователей.
- Первый deployment требует установки проверенного механизма на VPS, отдельных backup credentials и вручную запущенного Mac worker. Key recovery и initial provisioning описаны в docs/production-deployments.md.
- Main CI проверяет audit, UI и native amd64/arm64 runtime до публикации образа. Production deployment и приватная приёмка CAPTCHA/login/logout подтверждаются отдельно.

## [1.4.2] — 2026-10-12

### Исправлено

- Проверка повторного TOTP-входа использует тот же код, что и первый вход. Смена 30-секундного интервала больше не вызывает случайный отказ CI и блокировку публикации Docker-образа.
- Тест проверяет, что отказ повторного входа не создаёт дополнительную сессию администратора или запись успешного входа.

### Проверка выпуска

- GitHub Release публикуется после успешных main CI и Release eligibility с подтверждёнными amd64/arm64 images и точным digest.
- Деплой VPS выполняется отдельно; текст коллекций появится после обновления работающего образа.

## [1.4.1] — 2026-10-06

### Исправлено

- Форма обратной связи принимает ввод после подключения обработчиков; ранний ввод не теряется при гидратации.
- Настройки cookie объявляют диалог после подключения обработчика; UI-проверки ожидают фактическую готовность. Обычная ссылка на страницу cookie работает без JavaScript.
- Release gate принимает эквивалентные даты версии tag ruleset с разными часовыми поясами; реальное изменение защиты по-прежнему блокирует допуск.

### Ограничения и проверка

- GitHub Release публикуется без ожидания main CI и Release eligibility. Готовность Docker-образа требует успешных audit, полного UI, native runtime обеих платформ и проверки точного digest.
- VPS-деплой выполняется отдельно. Тексты коллекций из 1.4.0 появятся после обновления работающего Docker-образа.

## [1.4.0] — 2026-10-06

### Добавлено

- Локальный n8n на MacBook: закреплённый Docker-образ, loopback-доступ, постоянные workflows/credentials/Wait и Data Tables, приватные snapshots и восстановление в новый volume.
- Редакционные истории для пяти коллекций на четырёх языках.

### Изменено

- Лёгкие проверки веток и PR; полный UI, native runtime и публикация проверенных образов только на main. Защищённый релизный тег проверяет source SHA, CI run и точный digest без повторной сборки.
- Production Compose рассчитан на 1 CPU: app 512 MiB, миграции 128 MiB отдельно; proxy/egress и secrets разделены, права PostgreSQL проверяются по явному allowlist.
- Независимые настройки аналитики и рекламы с сохранением прежних отказов, региональными defaults и отзывом разрешения.
- Оценки, комментарии и обратная связь доступны независимо от страны и ошибки её определения.
- Публичные display-заголовки используют общий адаптивный размер 32-56 px; заголовки юридических страниц сохраняют прежний размер.
- Страницы 404 доступны на четырёх языках; неизвестные публичные URL используют язык префикса пути.

### Исправлено

- Поисковые страницы исключены из индексации и sitemap; canonical и hreflang согласованы для четырёх языков, добавлен статический `/llms.txt`.
- Email-ссылки защищены от обфускации Cloudflare; оригинальные PNG скачиваются через нативные GET-формы и доступны без JavaScript.

### Ограничения и проверка

- GitHub Release публикуется без ожидания main CI и Release eligibility. Допуск Docker-образа требует успешных audit, UI, native runtime обеих платформ и проверки точного digest; GitHub Release сам по себе не подтверждает готовность образа к deployment.
- Деплой VPS, настройки Cloudflare и повторный production SEO-аудит выполняются отдельно; связанные SEO-тикеты остаются открытыми до production-проверки.
- Snapshots n8n сохраняются вне репозитория с приватными правами доступа, без шифрования архива. Data Table node после просроченного Wait может завершиться ошибкой инициализации upstream; для журнала используется свежий polling execution с сохранённого checkpoint.

## [1.1.0] — 2026-10-05

### Добавлено

- Rust API и внешний PostgreSQL 18 для оценок, комментариев, жалоб, обращений и каталога.
- Приватная админка `/admin/login/` с паролем, TOTP, управлением переводами и модерацией.
- reCAPTCHA Enterprise для публичных изменений и входа; ошибки сохраняют введённые данные и позволяют повторить действие.
- Готовые Docker-образы для linux/amd64 и linux/arm64, проверенные перед публикацией в GHCR.

### Изменено

- Репозиторий разделён на frontend и backend; публичные маршруты и четыре языка сохранены.
- SEO и CDN настроены для https://wallpapers.want.foundation/ и https://want-foundation.s3.twcstorage.ru/.
- Firebase больше не хранит данные приложения; остаётся необязательная Analytics после согласия и проверки региона.
- Makefile и инструкции описывают Docker, существующий Traefik, внешний PostgreSQL 18/TLS, секреты и rollback.

### Ограничения и переход

- Перед запуском нужны две роли PostgreSQL, миграции/grants, внешние секреты администратора и JSON Google service account, проверенный Web Key ID reCAPTCHA.
- Социальные данные Firebase не импортируются. Изменения каталога попадают на статические страницы после export/rebuild.
- Для российских IP и при ошибке определения региона публичные социальные функции и Analytics скрыты; просмотр и скачивания работают.
- Прежние ограниченные исключения Bun audit действуют до 2026-11-04; новых Rust findings нет.
- Git release не выполняет деплой VPS. Реальный Google assessment, Analytics и production проверяются после развёртывания.

## [1.0.0] — 2026-10-03

### Добавлено

- Дизайнерские обои, объединённые в коллекции, с просмотром и скачиванием оригинальных PNG для компьютера и телефона.
- Каталог на русском, английском, китайском и бразильском португальском языках.
- Поиск по названиям, описаниям и тегам с фильтрами по коллекциям и категориям.
- Адаптивный интерфейс Want на shadcn/ui, локальные шрифты и превью без обрезки изображения.
- Оценки 👎 Dislike, 👍 Like, 💖 Love it и 🚀 Amazing с переводами, публичные комментарии и личная форма обратной связи.
- Настройки cookie, страницы контактов, лицензии и конфиденциальности.
- Статические страницы обоев и коллекций с canonical, hreflang, структурированными данными, robots.txt и sitemap.
- Инструкция деплоя на бесплатный Firebase Hosting Spark и проектный порядок выпуска фичи по Gitflow.

### Ограничения

- Для российских IP-адресов и при ошибке определения региона оценки, комментарии, обратная связь и аналитика скрыты. Просмотр, поиск и скачивание остаются доступны.
- Analytics требует подключения Google Analytics к Firebase, measurement ID и согласия посетителя.
- App Check требует регистрации ключа и проверки после развёртывания перед включением принудительной проверки.
- Рекламный провайдер пока не подключён.
- Публикация версии в Git не выполняет деплой Firebase Hosting.
