# История изменений

## Не выпущено

## [1.9.4] - 2026-10-21

### Добавлено

- Отдельный локальный путь выпуска с MacBook: проверки обеих платформ, подпись release evidence и deployment через существующий защищённый механизм. Обычные релизы сохраняют GitHub Actions.

### Исправлено

- Поиск загружается в браузерных ESM-модулях: состояние арабского stemmer больше не зависит от глобального `this`.

### Изменено

- HilltopAds заменяет прежние рекламные сети: один баннер 300×250 и штатные всплывающие окна с учётом независимого рекламного согласия. Скачивания PNG остаются доступны без рекламы.
- Выпуск использует профиль full с UI/E2E, audit, unit/API, collection drafts и native Runtime обеих платформ.
- Обложка README сохраняет пропорции при сжатии и показывает выбранные работы каталога. Английский и русский тексты сокращены; добавлены смайлики разделов и обновлено оглавление.
- Обложка README получила светлую и тёмную версии с пиксельной типографикой, фирменным логотипом и тремя превью коллекций. Оба README выбирают обложку по теме; светлая версия служит запасной.
- README на английском и русском получил центрированную шапку с логотипом, бейджи релиза и лицензии кода, счётчик звёзд и оглавление. Возможности проекта собраны в компактный список.
- README на английском и русском представляет проект, автора, FAQ, монетизацию и десять направлений развития в физическом мире и AR/VR. Добавлен фирменный баннер; подробные инструкции разработки и эксплуатации сохранены в отдельном руководстве.

### Ограничения

- Созданный, но незаполненный рекламный iframe может сохранять место на странице. Наличие iframe и загрузка тега не подтверждают фактический показ.
- Реальные рекламные показы, CAPTCHA и приватный password/TOTP вход требуют отдельной проверки на задеплоенной версии.

## [1.9.3] - 2026-10-20

### Добавлено

- Арабская локализация каталога, поиска, историй и публичных страниц с направлением RTL и локальным шрифтом Noto Sans Arabic.

### Исправлено

- Кнопка отправки обратной связи занимает всю ширину формы на отдельной странице и в диалоге.
- Боковые размещения Adsterra сохраняют отступы при увеличенном размере шрифта.

### Изменено

- Выпуск использует профиль fast: пропускается только Full UI/E2E. Static/type/format, unit/API, audit, collection drafts, обе native Runtime платформы и deployment gates обязательны.

### Ограничения

- Каталог и manifests требуют шесть непустых переводов: en, ru, zh-cn, pt-br, ja и ar. Старые записи с пятью локалями отклоняются при сохранении и публикации.
- Арабская миграция сохраняет существующие переводы и останавливается при неизвестной записи без перевода или изменённом английском источнике. Backup и off-VPS restore обязательны до остановки app и миграций.
- HTTP smoke и синтетические тесты не подтверждают реальные рекламные показы, CAPTCHA assessment или приватный password/TOTP вход.

- Миграция японских переводов останавливается при изменённом английском источнике или неизвестной записи без перевода. Миграции выполняются с остановленным app; автоматическое удаление переводов и Down не предусмотрены.
- HTTP smoke не подтверждает реальный CAPTCHA assessment, приватный password/TOTP вход или рекламные показы.

## [1.8.1] - 2026-10-20

### Изменено

- Все GitHub workflows запускаются вручную. Один protected-tag release запускает проверки, публикацию проверенных images без rebuild, eligibility и production deployment.
- Добавлен профиль fast: он пропускает только полный UI/E2E suite. Static/unit/API, audit, collection drafts, native amd64/arm64 runtime и backup/restore остаются обязательными. Профиль записывается в immutable evidence и проверяется на VPS; full выбран по умолчанию.

- Production smoke ожидает public readiness до 90 секунд, чтобы задержка healthcheck маршрута Traefik не вызывала преждевременный rollback. Остальные smoke checks сохраняются.
- Фон 3D-сцены стал прозрачным; заполненные controls и минимальные 44 px targets сохранены.

### Ограничения

- HTTP smoke не подтверждает приватный password/TOTP вход или реальный CAPTCHA assessment.

## [1.8.0] - 2026-10-20

### Добавлено

- Neon Tide: десять сюрреалистичных сцен со светящимися пикселями, тёмными берегами, мантой и лунными осколками. Для каждой доступны отдельные desktop/mobile PNG, названия, описания и история на четырёх языках. Каталог содержит 6 коллекций и 45 дизайнов.
- Приватный workflow n8n для подготовки и согласования новых коллекций: хранение черновиков, ограничения расходов, проверка версии при одобрении и резервное копирование локального состояния.

### Исправлено

- rustls обновлён до 0.23.46 с исправлением RUSTSEC-2026-0347; новые исключения audit не добавлены.
- Импорт коллекций работает при закрытых PostgreSQL function defaults: runtime получает EXECUTE только на существующую функцию даты публикации. Проверка привилегий отклоняет отсутствие этого права.
- Runtime-проверки новых коллекций учитывают собственное время импорта в тестовую БД и сохраняют даты при точном повторе, без подмены production-датами.

### Ограничения

- Подготовка черновика n8n не публикует коллекцию без отдельного согласования и выпуска.
- Локальные SEO и браузерные проверки не подтверждают результаты Semrush, поведение физических устройств или приватный production-вход администратора.

## [1.7.0] - 2026-10-14

### Добавлено

- Галерея использует графитовую палитру, акцент логотипа, компактную типографику и liquid glass. Компоненты и визуальные правила собраны в локальном UI-kit, DESIGN.md и AGENTS.md.
- Главная показывает коллекции в горизонтальном слайдере с пагинацией и обои в округлой композиции bento. Ручное вращение 3D-сцены выбирает другие обои для обоих экранов.
- Feedback открывается в модальном окне на текущей странице и сохраняет черновик. Языки сопровождаются флагами; контакты и footer содержат ссылку на GitHub проекта.

### Изменено

- На странице обоев изображение и панель скачивания занимают две колонки. Просмотр сохраняет размер при смене формата, показывает изображение целиком и заполняет свободное место размытым фоном.
- Стрелки, клавиатура и свайпы переключают обои без перезагрузки и скачков страницы. Формат, история и метаданные сохраняются. PNG скачивается без перехода на страницу файла.
- Поиск и навигация показывают новые обои первыми по неизменяемой дате публикации. Миграция заполняет даты для 35 существующих работ из истории выпуска каталога.
- Последние десять видимых комментариев расположены в горизонтальных карточках перед историей коллекции. Длинные комментарии и истории раскрываются по запросу; длинные тексты используют до трёх колонок.
- Карточки подсвечиваются волной при наведении и фокусе. Эффекты текста, конфетти и фон учитывают настройки доступности и не блокируют просмотр или скачивание.

### Исправлено

- Backup worker принимает дополнительные запрещающие S3-правила, сохраняя private prefix и отказ на неизвестные разрешающие правила. Bucket policy не меняется.
- Проверка сборки учитывает локализованный основной текст, контекстные ссылки и семантику PNG-скачивания. Публичная галерея содержит меньше служебного HTML.

### Ограничения

- Подготовленные региональные рекламные размещения остаются отключены до одобрения настоящих блоков.
- UI-kit доступен только в development и исключён из production-сборки.
- Проверки браузера не подтверждают поведение физических устройств или приватную production-приёмку CAPTCHA и входа администратора.

## [1.6.0] - 2026-10-13

### Добавлено

- Коллекции поддерживают MP4/H.264 видеообложки с PNG-постером. Видео загружается при появлении в viewport; пауза, reduced motion и ошибки воспроизведения сохраняют доступный постер. API и инструменты каталога проверяют адреса и media перед публикацией.

### Исправлено

- llms.txt сохраняет разрешения, запреты и владение из действующей лицензии, ссылки на Terms и четыре локали. Публичные страницы содержат discovery metadata; успешная выдача использует UTF-8 text/plain. Сборка проверяет структуру и актуальные публичные ссылки.

- Backup worker допускает точное изолированное public-media правило Prizmaxis, сохраняя исключение backups и отказ неизвестным S3 grants. Bucket policy не изменяется.

## [1.5.0] — 2026-10-12

### Добавлено

- Защищённый release tag запускает deployment точного проверенного образа через отдельный SSH account с ограниченными командами. Работающий сайт сохраняется до проверки образа, подключений и backup.
- Перед миграцией backup шифруется, сохраняется приватно на 30 дней и восстанавливается на Mac в изолированной PostgreSQL 18. При ошибке или недоступном worker миграция блокируется.
- Deployment сохраняет состояние и прежний образ/config. Автоматический rollback разрешён при подтверждённой совместимости schema/history; остальные ошибки требуют оператора.
- Ручной повтор использует исходный immutable digest и его успешный main run/attempt, даже после новой публикации того же commit.

### Исправлено

- Миграции используют только migrator URL/CA, egress и 128 MiB памяти даже при наследовании старого operational Compose.
- Добавлены проверяемые SQL-процедуры изоляции PostgreSQL от известных ролей других приложений и восстановления ограниченных runtime grants.

### Подготовка и проверка

- Установщик допускает ограниченные CI/backup SSH-учётки при существующем глобальном AllowUsers, сохраняя доступ администратора и запрет остальных пользователей.
- Первый deployment требует установки проверенного механизма на VPS, отдельных backup credentials и вручную запущенного Mac worker. Key recovery и initial provisioning описаны в docs/production-deployments.md.
- Main CI проверяет audit, UI и native amd64/arm64 runtime до публикации образа. Production deployment и приватная приёмка CAPTCHA/login/logout подтверждаются отдельно.

## [1.4.0] — 2026-10-06

### Добавлено

- Локальный n8n на MacBook: закреплённый Docker-образ, loopback-доступ, постоянные workflows/credentials/Wait и Data Tables, приватные snapshots и восстановление в новый volume.

- Лёгкие проверки веток и PR; полный UI, native runtime и публикация проверенных образов только на main. Защищённый релизный тег проверяет source SHA, CI run и точный digest без повторной сборки.
- Production Compose рассчитан на 1 CPU: app 512 MiB, миграции 128 MiB отдельно; proxy/egress и secrets разделены, права PostgreSQL проверяются по явному allowlist.
- Независимые настройки аналитики и рекламы с сохранением прежних отказов, региональными defaults и отзывом разрешения.
- Оценки, комментарии и обратная связь доступны независимо от страны и ошибки её определения.
- Публичные display-заголовки используют общий адаптивный размер 32-56 px; заголовки юридических страниц сохраняют прежний размер.
- Страницы 404 доступны на четырёх языках; неизвестные публичные URL используют язык префикса пути.

### Исправлено

- Поисковые страницы исключены из индексации и sitemap; canonical и hreflang согласованы для четырёх языков, добавлен статический `/llms.txt`.
- Email-ссылки защищены от обфускации Cloudflare; оригинальные PNG скачиваются через нативные GET-формы и доступны без JavaScript.

### Ограничения и проверка

- GitHub Release публикуется без ожидания main CI и Release eligibility. Допуск Docker-образа требует успешных audit, UI, native runtime обеих платформ и проверки точного digest; GitHub Release сам по себе не подтверждает готовность образа к deployment.
- Деплой VPS, настройки Cloudflare и повторный production SEO-аудит выполняются отдельно; связанные SEO-тикеты остаются открытыми до production-проверки.
- Snapshots n8n сохраняются вне репозитория с приватными правами доступа, без шифрования архива. Data Table node после просроченного Wait может завершиться ошибкой инициализации upstream; для журнала используется свежий polling execution с сохранённого checkpoint.
